# Audio

This folder mirrors the board's drive: copy `thunder/` (and `rain/`, if you use the rain button) to the root of `CIRCUITPY`.

Every file must be **16-bit mono WAV at 22,050 Hz**; the code skips anything else. Keep the total under about 6 MB.

| Folder | Plays when |
| --- | --- |
| `thunder/` | Thunder: one random clip per strike |
| `rain/` | Rain loop: toggled by the green button (`USE_RAIN_BUTTON = True`) |
